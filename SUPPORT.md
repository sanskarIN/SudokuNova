# SudokuNova Support

## Bug Reports

Use GitHub Issues for reproducible application bugs that are safe to discuss publicly:

https://github.com/sanskarIN/SudokuNova/issues

Please include the app version, Android version, device/emulator type, steps to reproduce, expected result, and actual result. Remove private information from screenshots and logs.

## Security Issues

Do not publish exploitable security vulnerabilities in a public issue. Follow `SECURITY.md`.
